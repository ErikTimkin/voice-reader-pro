# Voice Reader Pro

Локальная озвучка текста в голосовом канале Discord. Для синтеза не требуется внешний TTS API.

## Доступные голоса

- **Обычный мужской** — Silero v5.6, диктор Aidar.
- **Обычный женский** — Silero v5.6, диктор Baya.
- **Милый голос** — Silero v5.6, диктор Xenia.
- **Желейный медведь** — Xenia с локальной обработкой FFmpeg: повышенная высота тона и мультяшная подача. Это стилизация, а не копирование конкретного исполнителя.
- **Армянский 2.0** — Silero v5 CIS, диктор ru_safarhuja.
- **Кавказский акцент** — Silero v5 CIS, диктор ru_eduard.
- **Татарский оттенок** — Silero v5 CIS, диктор ru_marat.

## Модели и атрибуция

- **Silero voice model:** см. уведомления в папке voices; перед коммерческим использованием проверьте условия лицензии.

## Запуск

Распакуйте архив целиком и запустите VoiceReaderPro.exe. Не удаляйте рядом лежащие папки voices и tools. Все одиннадцать голосов стабильной версии №348 работают локально.


## Два режима

После запуска VoiceReaderPro.exe откроется выбор режима:

- **Текстовый бот** — восстановленная текстовая озвучка из стабильной версии №348.
- **Изменение голоса** — отдельный процесс для эффектов микрофона и вывода через VB-CABLE.

Режимы работают в отдельных процессах и не используют внутренние модули друг друга. Подробности и настройка виртуального кабеля: см. [TWO_MODES.md](TWO_MODES.md).
